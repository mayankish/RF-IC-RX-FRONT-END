\textbf{2.4\,GHz RF Receiver Front-End -- Analog IC Design} \hfill
{\small\textit{Cadence Virtuoso, Spectre RF, Python -- 180\,nm CMOS}}
\begin{itemize}

    \item Designed a complete \textbf{RF receiver chain} in \textbf{Cadence Virtuoso} (180\,nm CMOS, 1.8\,V): \textbf{cascode LNA}, \textbf{double-balanced Gilbert cell mixer} (2.4\,GHz\,$\to$\,200\,MHz IF), and \textbf{4\textsuperscript{th}-order Gm-C bandpass filter}; block specs derived via Friis noise and IIP3 cascade analysis linked to a companion 64-subcarrier OFDM baseband project.

    \item Ran DC, S-parameter, noise, and two-tone PSS\,+\,PAC simulations in \textbf{Spectre RF}: LNA -- \textbf{S21\,=\,15\,dB, NF\,=\,2.3\,dB, IIP3\,=\,$-$4\,dBm}; Gilbert mixer -- \textbf{conversion gain\,=\,7\,dB, DSB NF\,=\,11.4\,dB, IIP3\,=\,+6\,dBm, LO--RF isolation\,=\,34\,dB}.

    \item Verified Gm-C filter ($f_0$\,=\,200\,MHz, BW\,=\,20\,MHz) via Spectre AC sweep -- \textbf{stopband\,$>$\,40\,dB} at $\pm$40\,MHz; full-chain Pnoise confirmed \textbf{cascade NF\,=\,3.1\,dB} and \textbf{receiver sensitivity\,=\,$-$97.9\,dBm}, meeting the QPSK BER\,$<$\,$10^{-3}$ link budget.

\end{itemize}
